Di dalam kode ada daftar buku dan juga daftar kosong untuk menampung buku yang nantinya akan dipinjam. Saat program ini dijalankan, Peter akan mendapatkan pilihan menu. Mulai dari pinjam buku, membatalkan peminjaman dan melihat daftar peminjaman. Setiap Peter mengetik judul buku program akan otomatis mengecek apakah ada atau tidak diperpustakaan, jika ada akan dimasukkan ke daftar, jika ingin dibatalkan, buku bisa dihapus kembali. Setelah Peter selesai, program berhenti dan langsung mencetak daftar akhir buku yang Peter pinjam.
